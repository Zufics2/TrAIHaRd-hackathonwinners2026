## B. Парная серия: 4 вопроса × ChatGPT Search и Gemini × 2 прогона = 16 ответов

**Куда класть:** `~/Desktop/forme/paired_series/` (один файл на сборщика). Ничего не править на ноутбуке капитана.

**Предпочтительный формат — CSV** с заголовком из `data/templates/observations_template.csv`, разделитель `,` или `;`:

| Поле | Значение |
|---|---|
| response_id | `PS-P3-G-<prompt_id>-R1`, `…-R2` (G = Gemini, C = ChatGPT); уникален |
| prompt_id / query | ID и **дословный** вопрос — один и тот же текст для обоих AI и обоих прогонов |
| provider | `chatgpt_search` или `gemini` |
| search_mode | `search_on` |
| timestamp | время ответа с поясом: `2026-11-20T22:10+05:00` |
| run_no | `1` или `2` (новый чат для каждого прогона) |
| answer_text | весь ответ, без сокращений |
| cited_urls | все ссылки полностью (`https://…`), разделитель ` \| ` |
| data_type / verification_status | есть скриншот или share-ссылка → `MANUAL_VERIFIED` / `pending` + `evidence_link`; нет → `MANUAL_REPORTED` / `self_attested`, `evidence_link` пусто, в `notes` — откуда текст |
| collector | `P2` или `P3` — кто реально задавал вопрос |
| verified_by | пусто (проверяет **другой** участник позже) |

**Если удобнее Word** — тот же формат, что `Bridge.docx`, плюс две строки в каждом блоке: `Прогон: 1` и `Сборщик: P3`.

**Проверка до отправки:** `cd src && ../.venv/bin/python -m geolab.contract observations <файл>` → `ошибок 0`.

## C. Чтобы ответы стали verified

Скриншот всего ответа со ссылками (`assets/evidence/<response_id>.png`) или share-ссылка. Затем **другой** участник сверяет текст и ссылки и ставит `verified` + `verified_by` + что сверено в `notes`. Самопроверка и отсутствующий файл система отклоняет.
