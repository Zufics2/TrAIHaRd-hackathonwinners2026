## Научная интерпретация

Исходный корпус: 12 документов, шесть Центра Красок, четыре SVET.KZ, два Satu. Документов сайтов производителей **0**: ck_dulux и svet_maytoni принадлежат магазинам. Других специализированных магазинов красок **0**. Satu-страницы преимущественно на казахском; краски в выдаче включают промышленные и огнезащитные материалы, поэтому это слабая конкуренция русским запросам о детской. Люстры включены как соседняя категория/контроль, не как конкуренты красок.

Уникальных владельцев только три: любой найденный владелец неизбежно в Top-3. Следовательно, 100% означает в основном присутствие клиента в усечённой выдаче, а не победу над сильными релевантными конкурентами. BM25 ранжирует top-5 **документов**, затем deduplicate владельцев; это также не полный рейтинг всех магазинов.

| Метрика | Определение и применимость |
|---|---|
| MRR | Среднее reciprocal rank целевого владельца; отсутствие в извлечённых top-k документах = 0. Не средняя позиция. Локальная целевая видимость, не relevance MRR без qrels |
| Hit@3 / existing top3_rate | Доля запросов, где целевой владелец имеет entity rank ≤3; знаменатель все запросы роли. Одна целевая сущность → эквивалент target hit, не precision |
| Rank Position | Позиция владельца и отдельно изменённой страницы; None означает отсутствие в top-k. Сохраняются per-query; среднюю только по найденным не выдаём за общую эффективность |
| Changed page MRR | Reciprocal rank первой страницы из changed_doc_ids в top-k документов. Для EXP-001 страница одна; отделяет эффект самой правки от других страниц магазина |
| Recall@K | N/A: нет полного набора размеченных релевантных документов на запрос. Наличие клиента не заменяет qrels |
| Citation Coverage | Для настоящих ответов: ответы с ≥1 валидной citation / все ответы. В данном детерминированном retrieval ссылки генерируются из результатов, поэтому это не независимое свидетельство качества |
| Relevant Recommendation Rate | N/A: нет ручных relevance judgments и семантического ответа; returned owner не равен релевантной рекомендации |

Риск leakage: данные baseline/treatment не пересекаются через обучение модели (обучения нет), но тексты treatment и запросы созданы вручную для одного кейса. Они уже были известны авторам; это exploratory, не слепой holdout. Полный BM25 индекс пересчитывается в каждой ветке — меняется avgdl и иногда scores неизменённых документов, это штатное свойство retrieval. Нельзя требовать равенства scores controls; отдельно сохраняются флаги equality raw и entity ranks.
