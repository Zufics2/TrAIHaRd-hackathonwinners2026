# 08 · Протокол измерений и эксперимента

## 1. Два режима — никогда не смешиваются

| Режим | Что это | Статус данных | Что можно утверждать |
|---|---|---|---|
| MODE 1 · Live monitoring | реальные ответы ChatGPT Search / Gemini / Perplexity | `REAL`, `MANUAL_VERIFIED` | «сейчас AI отвечает так-то, цитирует такие-то URL» |
| MODE 2 · Controlled experiment | локальная BM25-симуляция стадии извлечения | `CONTROLLED_EXPERIMENT` | «в фиксированном корпусе правка X меняет извлечение страницы так-то» |

**Нельзя** утверждать, что правка изменила ответ ChatGPT, пока она не опубликована и не перемерена в MODE 1.

## 2. Ручной сбор ответов (MODE 1)

1. Новый чат / окно инкогнито. Без персональных инструкций и памяти. Режим поиска **включён** (ChatGPT: Search; Gemini: обычный режим с Google; Perplexity: по умолчанию).
2. Вставить `query` из `prompts.csv` **дословно**.
3. Скопировать **полный** ответ без правок в `answer_text`.
4. Все ссылки-цитаты — в `cited_urls` через ` | `. Если ссылок нет — пусто (это тоже данные).
5. `timestamp` в формате `2026-11-20T15:04+05:00`; `provider`: `chatgpt_search` / `gemini` / `perplexity` / `google_ai_mode`; `model` — если интерфейс показывает, иначе `unknown`.
6. `status=MANUAL_VERIFIED`, `collector` = инициал, скриншот → `assets/evidence/<response_id>.png` (без личных данных).
7. Приоритет: все P0-запросы × 2 провайдера × 2 повтора. Повторы нужны для `Result Consistency`.
8. `notes`: город устройства, VPN, вход в аккаунт — всё, что может влиять.

## 3. Контролируемый эксперимент (MODE 2)

Фиксировано: корпус (`corpus/baseline`, дата загрузки в каждом документе), токенизатор (`\w+`, lowercase, ё→е, префикс 5 символов), BM25Okapi (k1=1.5, b=0.75 — значения по умолчанию rank-bm25), `top_k`, список запросов.

Меняется: **только** документы из `changed_doc_ids` (файл в `corpus/treatment/` с тем же `doc_id`).

Answer engine: топ-k документов по BM25 → сущности-владельцы по порядку первого появления → ранжированный список + цитаты (URL документов). Никакого system prompt «рекомендуй нас».

Treatment-текст создаётся **только из фактов, подтверждённых на страницах клиента**; источник каждого факта указан в `provenance`.

Negative control: запросы другой категории/города, по которым целевой клиент не должен подниматься. Рост на них = деградация релевантности.

## 4. Метрики

| Метрика | Числитель | Знаменатель | N/A если |
|---|---|---|---|
| Mention rate (E) | ответы, где упомянута E | ответы в срезе | 0 ответов |
| Recommendation rate (E) | ответы, где E рекомендована (эвристика) | ответы в срезе | 0 ответов |
| Top-3 rate (E) | ответы с нумерованным списком, где rank(E) ≤ 3 | ответы с нумерованным списком | нет списков |
| Citation rate (E) | ответы с ≥1 URL, принадлежащим E | ответы с ≥1 цитатой | нет цитат |
| Assortment Brand Coverage | ответы слоя A, где названа ≥1 марка из ассортимента клиента | ответы слоя A | 0 ответов |
| AI Share of Voice (E) | ответы с E | Σ по сущностям того же уровня ответов с ними | 0 упоминаний |
| Citation coverage | ответы с ≥1 цитатой | все ответы | 0 ответов |
| Exp. Top-3 rate | целевые запросы, где клиент в топ-3 | целевые запросы | 0 запросов |
| Exp. MRR | Σ 1/rank (0 если нет) | целевые запросы | 0 запросов |
| Exp. citation rate | запросы, где процитирован документ клиента | запросы роли | 0 запросов |

Пример: 2 ответа; в первом нумерованный список «1. Maytoni 2. Eglo 3. Lussole», во втором текст без списка с ссылкой на svet.kz. Maytoni: mention 1/2 = 50%, Top-3 1/1 = 100%, citation 0/1 = 0%. Проверено в `tests/test_core.py::test_entity_metrics_denominators`.

## 5. Ограничения

- BM25 — лексическая модель; реальные AI-поисковики используют семантический поиск, переписывание запросов (fan-out) и знания модели о брендах. Симуляция показывает только механизм извлечения.
- Корпус мал (12 документов на 2026-11-20); ретейлеры-конкуренты по краскам пока не добавлены → Top-3 насыщается. Поэтому показываем MRR.
- Эвристика «рекомендации» ошибается на сложных формулировках; спорные случаи сверяются вручную.
- Один ответ модели ≠ закономерность. Выводы — только по повторам.

## 6. Журнал экспериментов

### EXP-001 — категория «Для детской», Центр Красок №1 (2026-11-20 13:19)
- Изменение: CK-005 (вводный блок из подтверждённых фактов + title с городами), документ `ck_kids`.
- Корпус: 12 документов (10 клиентских, 2 Satu.kz). OLX и e-katalog вернули 403 — исключены.
- Целевые запросы (4): Top-3 100% → 100% (насыщение); **MRR 0.75 → 1.00**; цитирование 100% → 100%.
- В baseline по T1 «Где в Астане купить краску для детской комнаты?» и T3 первой шла страница люстр svet.kz — после правки первая `ck_kids`.
- Negative control (3 запроса про люстры): Top-3 33% → 33%, без изменений. Центр Красок стоит на 2-м месте в N2 («люстра для спальни в Астане») и до, и после — это шум лексического поиска (совпадение «Астана», «купить», «спальни»), правка его не усилила.
- Вывод: эффект есть только в симуляции, на маленьком корпусе. Нужно: конкуренты-магазины красок в корпусе, повторить.
